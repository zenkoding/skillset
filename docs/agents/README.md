# Project knowledge: public catalog

Committed docs for agents working in this repo. One line per doc: what it
covers, when to open it. Private docs live in the store outside the repo (see "Project knowledge" in
`config/instructions/shared.md`).

- [domain.md](domain.md): how to read `CONTEXT.md` and `docs/adr/`. Open before exploring unfamiliar code or naming a domain concept.
- [issue-tracker.md](issue-tracker.md): GitHub issues via `gh`, issue forms. Open when creating, reading or triaging issues.
- [triage-labels.md](triage-labels.md): the five triage labels. Open when labelling or triaging issues.
