## Engineering skills

The build loop runs brief, grill, build, publish, review, address, test, debrief, one ticket at a time. Reach for these on your own:

- Something is broken or unexplained: run `fix-bug` to find the cause before changing code.
- Writing code for a feature or a fix: work test-first with `tdd`.
- I ask to open or update a PR: run `publish`.
- I ask to review a PR: run `review`.
- A PR has review findings, failing CI or a conflict with its base: run `address`.
- I ask to make something faster or cheaper with proof: run `optimize-performance`.
- The same mechanical mistake shows up twice: offer `codify`.
