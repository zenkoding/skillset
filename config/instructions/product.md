## Product skills

The product loop runs envision, scope-milestone, shape-epic, the build loop per feature, then retrospect. Reach for these on your own:

- An epic or milestone closes: offer `retrospect`.
- A design question only running code can answer: run `build-poc`.
- A contract other code depends on needs a design: run `create-rfc`. Once its implementation is verified, suggest `update-rfc`.
