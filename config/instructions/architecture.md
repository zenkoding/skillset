## Architecture skills

The architecture lane finds drift from the agreed architecture and performance hotspots, and fixes them through the build loop. Reach for these on your own:

- I ask to check the code against its architecture: run `find-drift`. To fix one drift issue: run `refactor`.
- I ask what to optimize or where the time goes: run `find-hotspots`.
- I ask to make something faster or cheaper with proof: run `optimize`.
