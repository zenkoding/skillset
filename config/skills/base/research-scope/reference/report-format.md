# Report and citations

Size the report to the question. Include the answer, evidence for substantive findings, useful trade-offs, unresolved disagreements, limitations, and sources. Distinguish sourced facts from inference and recommendations; avoid padding a narrow answer with irrelevant sections.

Cite the material that supports each claim, using readable links or a consistent reference scheme. Record source identity, relevant version/date, and exact code or document locations where applicable. Quotes must match their source. Never invent bibliographic details, access claims, or supporting evidence.

For supplied snapshots, cite their paths or identifiers and explain that live retrieval was not performed. If a claim cannot be verified, label its uncertainty or remove it. Before saving, check that references resolve and support the claims associated with them.

State which validation was actually performed. Distinguish optional checks from required gates left unmet; a required independent review remains incomplete without an independent reviewer.
