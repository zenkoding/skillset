# Working notes and resumption

Use notes when the task is large enough to benefit from them or may need to resume. Choose a private writable location consistent with the host/project instructions and record its path. Small tasks need no separate tracking ceremony.

Capture the question, scope and authorization, source identities/revisions, useful evidence, unresolved questions, checks actually run, and next steps. Keep enough context to resume without copying unrelated private data. Update notes at meaningful milestones.

On resumption, verify the notes still describe the current request and source state. Recheck stale or missing evidence; a recorded completion status is not proof. Preserve earlier findings when correcting them so contradictions remain understandable.

When delegating, supply the bounded question, relevant context and evidence, expected result, allowed write scope, and completion criteria. Transfer referenced material if the worker cannot access it. Independent work can run concurrently; overlapping edits should not. Missing or failed worker results remain gaps, and review by the same agent is self-review.
